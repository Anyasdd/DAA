1. Here we have to find the value in array using boolean. To find it we have to check each value in array with boolean until we find the right one.
2. In the first step I set the left search boundary because version count starts with 1. In the next step I set the right search boundary(n is the latest version). Then I set while loop. This loop will check each value until the left and right baundaries meet at one value because we need to  minimize the number of calls on each step. In the next step I find the middle of current statement. Then I use if-else statement where we call the API and check if the version is bad. If true it means that the bad version is here or on the left, so I shift the right boundary.If false it means that the all versions form 1 to mid are not bad versions. So I shift the left boundary. When while loop will finish it means that left and right boundaries are in one point and this is the point where narrowed range indicates the very first broken version. 
3. Time complexity is O(log n). In each step we devide by 2. The search stops when the interval is reduced to a single element. So k = log2(n)
4. Space complexity is O(1). I do not create any additional arrays, lists, or complex objects
